Unauthorized

This Neconyan is behind a login. Here is how to get back in.

  1. 1When the browser asks, enter the username and password from basicAuthUser in config.yaml. Cancel the prompt to see this page.
  2. 2Still refused? Re-type them. Both values are case sensitive and may contain spaces or symbols.
  3. 3Forgot them? On the server, edit config.yaml, set new values, then run sudo systemctl restart neconyan.
  4. 4Stuck in a loop or seeing an old page? Clear this site's cookies and cached data, or try a private window.
  5. 5Wrong address? Open the exact URL you normally use, for example https://neconyan.purabunny.cc.
  6. 6Several wrong tries in a row? Wait a minute for the rate limit to reset, then try again.
