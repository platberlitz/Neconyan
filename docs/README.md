# Neconyan documentation

The [official Neconyan handbook](https://platberlitz.github.io/neconyan-docs/) is the starting point for questions about using the app. It includes screenshot guides and a [macro reference](https://platberlitz.github.io/neconyan-docs/macros/).

Building an extension? Start with the [extension authoring guide](https://platberlitz.github.io/neconyan-docs/extensions/).

This folder holds feature references and development notes alongside the code. To suggest a correction to the handbook, use the [documentation repository](https://github.com/platberlitz/neconyan-docs/issues).
