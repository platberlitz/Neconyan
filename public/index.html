                    Import from another instance
                    
                    Creates a separate copy of this character with all the chats you select in Import Chat. Nothing is merged with existing history, even if the names match. Adoption is one-way: the copy has no continuity link to its source. Normal ghost-writer protections apply afterwards. Leave this off to keep strict origin and seal checks.
