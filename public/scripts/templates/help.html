Miso Getting around: commands, formatting and shortcuts

Meowlcome~! I'll show you the quick stuff first, so you can do things without digging through menus. And if this helps, a belly rub would be lovely. Just saying, hehe.

Slash commands

A slash command is an instruction you type into the chat box instead of a message. Type / and a list of matching commands pops up, each with a short description. Press Enter to run the one you want.

/?
Opens this guide. Add slash, macros, format or hotkeys for a full list, like /? macros.
/sys The rain stops.
Posts a narrator message into the chat without asking the model to reply.
/continue
Asks the model to keep writing its last reply.
/hide 4
Hides message number 4 from the model. You can still see it, and /unhide 4 brings it back.
/gen A one-line café description
Asks the model for text and hands it to the next command instead of posting it.
/echo Hello!
Shows a small pop-up notice.

Put | between commands to run them one after another. Each command's result reaches the next one as {{pipe}}, so /gen A one-line café description | /echo {{pipe}} shows the model's answer in a pop-up.

Taro Macros: placeholders that fill themselves in

Taro. Give me a second, my voice is a little rough today. A macro is a word in double curly brackets, and right before anything goes to the model, Neconyan swaps it for the real value. Write it once, and it stays right no matter who you're talking to. That's a purr-fectly good deal. Tell me that was funny.

Where they work

Character cards, presets and prompts, lorebook entries and slash commands. Write {{char}} in a prompt and it becomes the name of whichever character you're chatting with.

Names and the character card

{{user}}
Your persona's name.
{{char}}
The character's name.
{{group}}
Everyone in a group chat, separated by commas. In a one-to-one chat it's just the character.
{{persona}}
Your persona's description.
{{description}} {{personality}} {{scenario}}
Those fields from the character card.
{{model}}
The name of the model you're connected to.

The chat so far

{{lastMessage}}
The newest message in the chat.
{{lastUserMessage}} {{lastCharMessage}}
Your newest message, or the character's.
{{input}}
Whatever is typed in the chat box right now.

Time

{{time}} {{date}} {{weekday}}
The current time, date and day of the week. {{time::UTC+2}} uses another time zone.
{{idleDuration}}
How long it's been since your last message.

Random picks and dice

{{random::tea::coffee::cocoa}}
Picks one option, and picks again every time.
{{pick::tea::coffee::cocoa}}
Picks once and keeps that answer for this chat. /reroll-pick picks again.
{{roll::1d20}}
Rolls dice, here one twenty-sided die.

Variables

A variable is a named value that Neconyan remembers for you. Local variables belong to the current chat; global variables are shared by every chat.

{{setvar::hp::20}}
Saves 20 under the name hp. It leaves no text behind.
{{getvar::hp}} or {{.hp}}
Reads it back.
{{addvar::hp::5}} {{incvar::turns}}
Adds 5 to hp, or adds 1 to turns.
{{.hp -= 5}} {{.turns++}}
The short way to change a local variable.
{{setglobalvar::gold::100}} or {{$gold}}
The same idea for global variables.

Conditions and tidying

{{if .hp}}Still standing.{{else}}Down!{{/if}}
Shows the first part when the condition has a value, otherwise the part after else. Empty, false, off and 0 count as no. Put ! in front to flip it.
{{// a note to yourself}}
A comment. It disappears before the model sees anything.
{{newline}} {{trim}}
Adds a line break, or removes the blank lines around it.

Arguments go after the macro's name, separated by ::. You can put macros inside macros; the inner one is worked out first.

Nori Macro Enhanced: cheaper prompts and fancier macros

Nori here. Macro Enhanced is the extension that comes with Neconyan and teaches macros some manners. I invented it, obviously. ...Fine, I didn't. But it saves you money, and I have very expensive taste and a very empty wallet, so listen closely.

Why it saves money

Some providers keep the unchanged start of your prompt ready between messages, which is called prompt caching. It makes replies cheaper and faster, but only while that start stays exactly the same. A macro that changes every message, like {{time}} or {{random}}, spoils it every time. Swap them for these:

{{timeofday}}
Morning, afternoon, evening or night, instead of {{time}}.
{{season}}
The season instead of {{date}}. {{season::south}} for the southern hemisphere.
{{listpick::drink::tea, coffee, cocoa}}
The same pick every time in this chat, instead of {{random}}.
{{rollonce::strength::3d6}}
Rolls once and keeps the total, instead of {{roll}}.
{{freeze::weather::{{random::stormy::misty::clear}}}}
Works out whatever is inside once and keeps it for the rest of this chat.
{{sticky::10::mood::{{random::tense::playful}}}}
Same idea, but refreshes after every 10 of your messages. {{daily::key::...}} refreshes once a day.

/me-audit finds macros in your presets, character, persona and lorebooks that spoil caching. /me-unfreeze clears kept values so they roll again.

Comparisons and maths

{{gt::{{getvar::hp}}::10}}
Says true when hp is above 10. Also eq, neq, gte, lt and lte, plus and, or and not. Put one inside {{if}} to act on it.
{{switch::{{getvar::mood}}::happy=She beams.::sad=She sighs.::default=She waits.}}
Picks the text that matches the value.
{{calc::(3 + 4) - 2}} {{clamp::{{getvar::hp}}::0::100}}
Does the sum, or keeps a number between two limits.
{{expr::{{getvar::day}} > 3}}
Writes a whole comparison in one go. The setting 'Work out comparisons in if conditions' lets {{if}} do this directly.

Text tools

{{default::{{getvar::mood}}::calm}}
Uses calm when mood is empty.
{{truncate::{{description}}::300}}
Cuts text down to 300 characters.
{{replace::the cat sat::cat::dog}} {{upper::hi}}
Swaps words, or changes capital letters.

Chat variables

These live in the chat file and are kept separately from Taro's {{setvar}} variables.

{{setchatvar::location::Forest}} {{getchatvar::location}}
Save a value and read it back.
{{addchatvar::minutes::15}}
Adds to it.
{{foreachChatVar::stat_::s}}{{.s}}: {{.s_value}} {{/foreachChatVar}}
Repeats for every chat variable whose name starts with stat_, in alphabetical order.

Lorebooks and pronouns

{{lore::Backstory}}
Pulls in the text of the lorebook entry called Backstory. {{lore::Kingdom::My World}} looks in one book. Right after a chat opens it can come back empty for a moment.
{{sub}} {{obj}} {{poss}} {{ref}}
Your persona's pronouns, like she, her, her and herself. Add char in front for the character's, like {{charsub}}. A capital letter, like {{Sub}}, capitalises the result.
{{pverb::is::are}}
Picks the verb that fits the pronouns. Set pronouns in Macro Enhanced's settings, or for one chat with {{setpronouns::he/him}}. Until you do, it's they and them.

Your own macros

Make one in Extensions, under Macro Enhanced, then Your custom macros, or type it out:

/me-define name=greet args=who Hello {{who}}, good {{timeofday}}!
Now {{greet::Alice}} writes a greeting for Alice. A macro can belong to everything, one character or one chat; the narrowest one wins.

If a macro name clashes with another extension, Macro Enhanced's version is still there with me- in front, like {{me-upper::hi}}. /me-macros lists everything it added.

Macro Workbench

The Workbench is a practice area. Try macros in the Playground without touching your real variables, look things up in the Reference tab, and check caching in the Cache Audit tab. /me-workbench opens it too.

Macro Enhanced needs to be switched on under Extensions. If it's off, the macros in this section won't work.
