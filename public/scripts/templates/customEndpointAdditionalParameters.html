Additional Parameters

Include Body Parameters

Extra keys added to every request body. One key per line, written as name: value.

Exclude Body Parameters

Keys removed from every request body before it is sent. One key per line, each starting with a dash.

Include Request Headers

Extra HTTP headers sent with every request. One header per line, written as Name: value. An Authorization header here replaces the saved API key.

Reasoning Parameter

Adds one key to the request body that switches the model's reasoning on or off. It follows the Request model reasoning toggle and the Reasoning Effort setting. A key of the same name in Include Body Parameters wins.
Sends your Reasoning Effort setting as text, for example high. Nothing is sent when the effort is None, except to GPT-5.1 and newer, which receive none. Sends true when reasoning is requested and false when it is not. Sends the Enabled Value when reasoning is requested and the Disabled Value when it is not. Sends an object with a type field: the Enabled Value when reasoning is requested, the Disabled Value when it is not. This is the shape GLM and Kimi endpoints expect for a thinking key.
